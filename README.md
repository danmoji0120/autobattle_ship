# FLEET COMMAND — 다중 계층 지휘형 우주 함대 오토배틀러

함대를 편성하고, 지휘관을 배치하고, 임무를 맡긴다. 전투는 지휘관들이 각자의 능력과 성향으로 치르고,
플레이어는 전술 지도에서 흐름을 읽다가 결정적인 순간에 개입한다.

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # 시뮬레이션 테스트 (결정론/리플레이/지휘관 효과/장갑 모델 …)
npm run balance    # 헤드리스 대량 전투로 승률·전투 시간·무기별 피해 비중 확인
npm run build      # 정적 빌드 (dist/)
```

URL 옵션: `?auto=1` 편성 생략하고 바로 전투, `&scenario=kestrel|bastion|wolfpack`, `&seed=N`, `&cam=director`.

## 플레이 방법

1. **함대 편성** — 시나리오 선택 → 부대(그룹)를 만들고 하위 부대를 중첩 → 함선 추가·무장(로드아웃) 선택 → 지휘관 배치 → 초기 명령과 자동 후퇴 기준 설정 → 출격.
   기본 편성(제7 기동함대)은 바로 출격해도 되도록 구성되어 있다.
2. **전투** — 지휘관들이 스스로 싸운다. 플레이어는:
   - 좌측 **지휘 계통**에서 부대를 선택(▸로 펼치기/접기, 펼친 단계까지 지도에 부대 표식이 나뉘어 표시됨)
   - 하단 **명령 패널**: 자유 교전 / 공격 / 좌·우측 우회 / 호위 / 이동 / 사수 / 후퇴 / **지휘권 위임**, 위험 시 자동 후퇴 기준
   - **우클릭** 상황 명령: 적 → 공격(Shift: 특정 함선 집중), 아군 → 호위, 빈 곳 → 이동
   - 상위 부대에 명령하면 그 지휘관이 하위 부대에 역할을 나눠 준다. 하위 부대에 직접 명령하면 그 부대는 "직접 지휘"(주황 표시) 상태가 되고, `T`로 다시 위임할 수 있다.
3. **관찰** — `전술 지도` / `추적`(더블클릭) / `시네마틱`(자동 연출, 대형함 격침 시 슬로모션). 우측 통신 로그를 클릭하면 해당 위치로 이동.
4. **결과** — 하이라이트, MVP 함선, 지휘관별 평가. `리플레이 보기`는 같은 시드와 기록된 명령으로 전투를 완전히 재현한다.

단축키: `Space` 정지, `1-4` 배속, `Tab` 전술/시네마틱, `F` 추적, `C` 시네마틱, `E/A/Q/R/G/M/H/B/T` 명령, `Esc` 취소.

## 설계

| 층 | 내용 |
|---|---|
| `src/sim/` | 렌더링과 분리된 **결정론적 시뮬레이션** (30Hz 고정 스텝, 시드 RNG). 저장·리플레이·헤드리스 밸런싱의 기반 |
| `src/sim/ai/commander.ts` | **계층형 지휘관 AI** — 상위 그룹은 명령을 해석해 하위 그룹에 역할 분배(모루/망치/호위), 말단 그룹은 표적 선정·집중 사격·교전 거리·대형·우회 단계·뇌격 돌입을 수행 |
| `src/render/` | Three.js: 절차적 함선 모델(진영별 실루엣, 회전 포탑, 엔진 플룸, 반파 시 앞뒤로 분리되는 잔해), 성운 스카이박스, 인스턴스 파티클, 예광탄 리본, 충격파, 섬광 조명, 블룸, 시네마틱 디렉터 |
| `src/ui/` | 편성 화면, 전투 HUD(계층 트리, 명령, 통신, 전술 오버레이), 결과 화면 |
| `src/audio/` | 에셋 없이 코드로 합성한 효과음과 전투 강도에 반응하는 음악 |

### 지휘관이 전투 양상을 바꾸는 방식
- **판단력(skill)**: 판단 주기(0.9~3.4초), 표적 선정 품질(장갑 상성·고립·손상도 vs 단순 최단거리), 집중 사격과 과잉 살상 분산, 마무리 일격, 측면 위협 탐지, 우회 경로의 폭, 함대 속도 동기화, 망치-모루 타이밍(예: 바로스 제독은 뇌격대를 대기시켰다가 주력이 적을 붙잡는 순간 돌입 신호를 보낸다), 신참은 우회 명령을 잘못 이해하기도 한다(그레이 대위).
- **공격성(aggression)**: 교전 거리, 어뢰 발사 거리, 후퇴 시점.
- **규율(discipline)**: 낮으면 플레이어 명령 중에도 기회를 보면 독자 판단으로 돌입(카이 렌), 불만을 표시.
- **특기**: 포술(명중), 기동(속도·선회), 방공(요격률), 전술(판단 속도).
- 같은 함선에 지휘관만 바꾼 대조 실험: 지휘관 배치 함대가 "선임 함장" 함대에 약 19:1로 승리 (`scripts/cmdtest.ts`).

### 전투 모델 요점
전면/측면/후면 장갑과 관통력 → 관통·저지·**도탄**, 치명타(기관·포탑·화재·함교), 격침 시 탄약고 유폭(주변 함선 연쇄 피해),
미사일은 탄창 제한(초반 일제 사격 → 포격전으로 전환), 근접 방어포가 미사일·어뢰를 요격, 작고 빠른 함선은 맞추기 어렵다.

## 검증 현황
- `npm test`: 결정론, 리플레이 일치, 모든 시나리오 종료, 지휘관 효과, 직접 지휘/위임, 후퇴 이탈, 장갑 모델.
- `npm run balance`: 미러 매치 50:50(진영 편향 없음 확인 — 이 과정에서 발사 순서/조준 편향 버그를 발견·수정), 시나리오별 기본 편성 자동 진행 승률 약 40~70%, 전투 시간 약 3~4분.
- `scripts/shot.mjs`: 헤드리스 Chromium으로 실제 화면 캡처(편성, 전술 지도, 추적, 시네마틱).
- **자동 테스트로 판단할 수 없는 부분**: 연출의 박력, 사운드 믹스, 조작감, 장시간 플레이 재미는 직접 플레이로 확인이 필요하다. 헤드리스 환경은 소프트웨어 렌더링이라 실제 GPU 프레임레이트는 측정하지 못했다.
