# A-3.1 — 세력별 창업 배경

새 PMC는 설립할 때 회사 이름과 함께 여섯 가지 창업 배경 중 하나를 고른다. 배경에 따라 다음이 정해진다.

- 시작 위치(성계·정거장)
- 함선과 지휘관
- 시작 자금
- 세력 신뢰도

배경은 **시작 조건일 뿐이다**. 설립 뒤에는 어떤 활동, 시장, 선체, 설계도도 출신 때문에 막히지 않는다. 모든 것은 기존 규칙(신뢰도, 신용도, 연구, 자금)을 따르고, 시작 신뢰도도 다른 신뢰도처럼 오르내린다.

코드 위치:

- 배경 정의: `src/world/backgrounds.ts`
- 생성: `sim.ts` `addPlayer(name, background)` → `createFromBackground`
- 서버: `core.ts` `createPmc`
- 설립 화면: `client/account.ts` `showPmcCreate`
- 테스트: `tests/a31-backgrounds.test.ts`
- 브라우저 검증: `scripts/a31/a31-browser.cjs`

## 1. 여섯 배경

- **운영비/h**는 정박 상태의 실제 `forecast`와 같은 식으로 계산했다. 선체 운영비, 오버헤드 10%, 장비 소모품의 모항 시장가를 더한다. 테스트에서 설립 직후 `forecast(w, co).perHour`와 정확히 일치함을 확인했다.
- **함대 가치**는 공영 조선소 정가 기준이다.
- **초기 세력 신뢰도:** 모든 배경이 출신 세력 +10(협력)으로 시작한다. 출신 세력과 관계가 −50 이하인 세력은 −5(불신)로 시작한다.

  | 배경 | −5로 시작하는 세력 |
  |---|---|
  | 채굴업자, 경비업체, 퇴역 군사조직 | 해적 연합 |
  | 약탈자 | 연합 관리청, 철갑 사령부, 광업동맹 |
  | 운송업자, 인양업자 | 없음 |

  나머지 세력은 0(중립)이다.

### 1.1 배경별 근거

- **운송업자:**
  - 화물을 사야 수입이 생기므로 거래 자본(30,000)을 가장 많이 준다.
  - 대신 함선은 수송선 2척(운영비 677/h)이고 전투함은 없다.
  - A-2.1에서 확인했듯, 수송선만 있고 자금이 없으면 수입원이 없다. 그래서 자금이 오래 버티게 했다.
- **채굴업자:**
  - 앤빌 성계에 광구 3곳(광석, 티타늄, 고밀도)과 광석을 사는 광부조합 시장이 있다.
  - 수송선 1척을 함께 주어, 채굴 편대가 광석을 넘길 수 있게 했다.
  - 광부조합의 거래 예산은 35,000으로 작아, 많이 캐면 세레스(1점프) 등으로 운반해야 한다.
- **인양업자:**
  - 실제로 인양 가능한 함선으로 구성했다.
    - 공작선 S: 장비·선체·설계 조각
    - 채굴선: 선체 고철
    - 수송선: 화물
  - 무료 잔해나 자원은 주지 않는다.
  - 표준 월드(시드 21)를 4시간 돌려 보니 잔해 36곳이 생겼다. 위치는 엠버 29, 아스트라 5, 드레이크 2이다.
    - 대부분 선체 고철이었고, 일부에 장비와 화물이 있었다.
    - 세레스에서 아스트라는 1점프, 엠버는 2점프다.
    - 세레스 자체에는 잔해가 생기지 않았다. 초기 인양 경로는 A-3.2에서 정한다.
- **경비업체:**
  - 소형 전투 편대와 기본 지휘관.
  - 구축함은 넣지 않았다(아래 2절).
- **퇴역 군사조직:**
  - 운영비가 가장 높고(1,788/h), 자금은 5.5시간분이다. 군사 배경의 높은 부담을 반영한 것이다.
  - 숙련 지휘관을 준다.
  - 불워크 군항에는 조선소가 없다.
- **약탈자:**
  - 블랙게이트(해적 수도) 성계에는 정거장이 없다. 그래서 해적 연합의 공개 정거장인 **녹슨 정박지(검은 송곳니 공역)**에서 시작한다. 지시서의 "검은 관문"에서 바뀐 부분이다.
  - 녹슨 정박지는 해적 세력 시장이고 무법 지역 암시장(`bm_lawless`)이 있다.
  - 자금이 가장 적다(6,000).

## 2. 청산·악용 방지

- 어떤 배경에도 구축함 이상을 넣지 않았다. 모든 함선은 S 정박 규격, 공영 조선소 판매 선체, 표준 구성이다.
- 함대 가치는 18,600~45,600이다. 기존 시작은 150,300이고, 대부분이 구축함 116,500이다.
- A-2.1 긴급 매각(목록가 50%)으로 받을 수 있는 최대액은 퇴역 군사조직의 약 22,800이다. 이 정도는 정상 운영 수입보다 유리하지 않다.
- 기존 시작 구축함(약 58,000에 현금화 가능)과 관련해 A-2.1에서 남겼던 판단 사항은 배경 시작에서는 생기지 않는다. 기존 시작은 배경 없이 설립하는 경로에만 남는다(4절).

## 3. 신뢰도와 P14

- 출신 세력 +10은 P14의 첫 우호 구간(협력, 10~24)이다. 기록이 필요한 신뢰 구간(40 이상: 계약 8건, 4시간)과는 거리가 멀다.
- 설계도 조건과의 관계:

  | 배경 | 신뢰도 조건만 충족하는 설계도 | 남은 조건 |
  |---|---|---|
  | 운송업자(길드 +10) | 수송선 L(신뢰 10, 고급) | 연구 `logistics_ai`, 영향력 40, 55,000 cr |

  - 이 밖에 출신 신뢰도만으로 열리는 세력 설계도는 없다(다른 세력 설계도는 신뢰 12 이상).
  - 연합·철갑 출신은 자기 세력 조선소에서 구축함(신뢰 10 필요)을 살 수 있다. 정상가 116,500을 내고 사는 구매이며, 지급이 아니다.
- 출신은 영구적인 소속이 아니다.
  - 시작 신뢰도는 일반 증감 규칙을 따른다.
  - 약탈자도 회사 종류는 `player`(독립 회사)다. 해적 연합 소속이 되지 않는다.

## 4. 서버 권한·저장·호환

- **서버 결정:**
  - 클라이언트는 `createPmc { name, background }`로 배경 **id만** 보낸다.
  - 서버는 `backgroundOf`로 id를 확인한다. `Object.hasOwn`으로 검사하므로 `__proto__` 같은 키는 거부된다.
  - 함대, 자금, 신뢰도는 서버 표(`BACKGROUNDS`)에서만 나온다. 메시지에 다른 필드(자금, 함선)를 넣어도 읽지 않는다(테스트로 확인).
  - 이 세계에서 쓸 수 없는 배경 id를 보내면 "이 세계에서 선택할 수 없는 창업 배경입니다"로 거부되고, 아무것도 생성되지 않는다.
- **중복 지급 없음:** 계정에 이미 PMC가 있으면 `createPmc`는 기존 회사로 입장시킨다. 같은 계정의 재요청, 두 번째 탭, 재접속은 모두 같은 회사가 되고 추가 지급은 없다.
- **저장:**
  - 출신은 `Company.background`에 저장된다.
  - 저장/복원과 서버 재시작 뒤에도 출신, 모항, 함선, 신뢰도가 그대로다(단위 테스트와 실서버 브라우저 검증).
- **기존 회사:** 바꾸지 않는다. 배경 이전에 만든 회사는 `background`가 없고, 새로 지급받거나 초기화되지 않는다.
- **배경 없이 설립하는 경로:**
  - 배경을 보내지 않으면(구 클라이언트) 기존 아스트라 시작이 그대로 생성된다.
  - 단일 플레이어(`hello`)도 기존 시작이다.
- **레거시 월드:**
  - P10 세력이나 시작 정거장이 없는 월드는 배경 목록을 보내지 않는다(`backgroundsOn`).
  - 설립 화면은 기존 화면 그대로이고, 기존 시작으로 생성된다.
- **BB-EX:** 지급 규칙을 바꾸지 않았다. 독점 소유 계정은 배경 회사로 설립해도 BB-EX를 한 번만, 그 회사의 모항에서 받는다. 다른 계정은 받지 않는다(테스트로 확인).
- **정박:** 설립 함선은 모항 정박 위치에 바로 놓인다. 정박 이벤트(검문, 암시장 접촉)는 일으키지 않는다.

## 5. 설립 화면

- 이름 입력 아래에 배경 카드 6개가 나온다. 데스크톱은 3열, 900px 이하는 2열, 560px 이하는 1열이다.
- 각 카드에는 다음이 표시된다.
  - 세력
  - 성계와 정거장
  - 자금, 함선 수, 운영비
  - 난이도
- 카드를 고르면 상세가 열린다.
  - 설명
  - 시작 위치
  - 자금
  - 함선(선체, 수, 역할)
  - 지휘관
  - 예상 운영비와 버티는 시간
  - 함대 가치
  - 세력 신뢰도(구간 이름 포함)
  - 추천 활동
  - 주의 사항
  - "출신은 시작 조건일 뿐" 안내
- 표시 값은 모두 서버가 보낸 `needPmc.start.backgrounds`이다. 실제 지급과 같은 표에서 계산한다.
- 배경을 고르지 않고 설립하면 화면에서 거부한다.
- 레거시 월드나 구 서버(배경 목록 없음)에서는 기존 문구와 기존 동작을 유지한다.

브라우저 검증의 진행 순서:

1. 새 계정(1440px)에 카드 6개가 서버 값으로 표시됐다.
2. 배경 없이 설립하자 거부됐다.
3. 인양업자 상세가 표시됐고, 세레스 제련단지에 함선 3척, 12,000 cr, 세레스 +10으로 설립됐다.
4. 상단 운영비가 카드의 1,065 cr/h와 같았다.
5. 서버를 재시작하고 다시 로그인하자 같은 회사, 같은 함선으로 들어갔고 설립 화면은 나오지 않았다.
6. 두 번째 계정(390px 모바일)에서 카드 6개가 화면 안에 들어갔고, 가로 스크롤은 없었다.
7. 채굴업자 상세를 열고 앤빌 광부조합에 설립했다. 첫 계정과 다른 위치다.
8. 페이지 오류와 콘솔 오류는 없었다.

전체 회귀 테스트와 장기 시뮬레이션은 이번 단계에서 실행하지 않았다(위험 기반 검증 방식). 배경별 실제 플레이 수익성은 A-3.2·A-3.3에서 측정한다.

## 7. 남은 사항

- **A-3.2**(기본 네 배경의 초기 수입 활동):
  - 운송업자의 첫 교역 경로
  - 인양업자의 초기 인양 경로(세레스에는 잔해가 없고, 아스트라 1점프·엠버 2점프)
  - 경비업체의 첫 계약
  - 배경별 첫 몇 시간 수익성 측정
- **A-3.3**(군사·해적 배경의 특수 경험):
  - 해적 NPC는 출신과 무관하게 모든 플레이어 회사를 공격한다(`coRelation` 고정 규칙). 그래서 약탈자 회사도 검은 송곳니 공역에서 해적의 공격을 받는다. 이번 단계에서는 바꾸지 않았다.
  - 녹슨 정박지 암시장은 설립 시점에 자동 발견되지 않는다(정박 이벤트를 일으키지 않음). 처음 다시 정박할 때 기존 규칙대로 발견된다.
  - 퇴역 군사조직의 운영비 부담(5.5시간분)이 실제 전투 수입으로 감당되는지 측정이 필요하다.
- 운영 서버에 적용하려면 배포가 필요하다. 승인 전에는 하지 않는다. 기존 운영 월드의 회사는 바뀌지 않는다.
