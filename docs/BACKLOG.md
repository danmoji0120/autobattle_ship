### TD-1. P13.2.2 실서버 시험 S7·S8-4의 시간·순서 의존 불안정성

- **발견**: P13.3 회귀 검증(2026-11, `feature/p13-3-black-market-smuggling`).
- **근거**:
  - `artifacts/p1322/server-p133-regression.json`: 114/116. S8-4 두 건이 실패했다. 시작 4초에 화면에는 컨테이너가 보였지만, 0.5초 간격으로 쓰는 세이브 파일에는 아직 없었다. 같은 S8의 정확 보존 검사(300/300)는 통과했다.
  - `artifacts/p1322/server-p133-regression-2.json`: 112/113. S7 「no container 6」. 약탈 쌍 하나가 600초 안에 컨테이너를 만들지 못해 이후 단계가 실행되지 않았다.
  - `artifacts/p1322/server-base-7e7363c-flake-check.json`: **P13.3이 없는 기준 커밋 7e7363c**를 별도 worktree에서 빌드해 돌렸다. 112/113, S7 「no container 5」로 같은 유형이다.
- **판단**: P13.3 변경은 `blackMarketV` 조건 뒤에 있어 P13.2.2 월드에서는 실행되지 않는다. 기준 커밋도 같은 실패를 내므로 시험 자체의 불안정성이다.
  - S7: 실서버 실시간 진행과 여러 약탈 쌍의 접근·요구 순서에 따라 600초 제한 안에 투하가 일어나지 않는 경우가 있다.
  - S8-4: 화면 스냅숏과 세이브 파일 사이의 기록 지연(경쟁 상태)이다.
- **영향**: 기능 결함의 증거는 없다. 다만 회귀 판정에서 잡음이 생겨, 실제 회귀가 같은 실패 유형에 묻힐 위험이 있다.
- **제안**:
  - S7: 약탈 쌍별 제한 시간을 실제 접근 거리로 계산하거나, 쌍 하나의 실패가 이후 단계를 막지 않도록 분리한다.
  - S8-4: 세이브 파일 확인 전에 「다음 저장 완료」를 기다린다(세이브 파일 mtime 또는 서버 로그 기준).
  - 같은 시드로 3회 반복해 안정성을 확인한다.
- **상태**: 미해결. 시험 코드는 수정하지 않았다.
- **P13.4 재확인(2026-11)**: P13.4 변경은 모두 `lawV` 조건 뒤에 있어 P13.2.2·P13.3 월드에서는 실행되지 않는다. 단, P13.3.1에서 세관 반환 규칙이 바뀌어 `scripts/blackmarket/p133-server.ts` S4·S5의 기대값을 새 규칙으로 고쳤다(본거지 반환 → 세관 보관, S5는 자동 하역 차단과 직접 입항 검문으로 분리). S7·S8-4가 있는 P13.2.2 실서버 시험(`p1322` 계열)은 이번에도 수정하지 않았다. 판단 근거는 위 기준 커밋 재현 결과 그대로다.

## UI 백로그

### UI-1. 390px 폭에서 편대 선택 패널이 정거장 창(모달)을 가림

- **발견**: P13.3 브라우저 검증(2026-11).
- **근거**: `artifacts/p133/browser/preexisting-sel-over-modal-390.png`. 암시장이 없는 아스트라 시장 탭에서도 같으므로 P13.3 이전부터 있던 문제다.
- **재현**: 390px 뷰포트에서 편대를 선택한 상태로 정거장 창을 연다. 편대 선택 패널이 정거장 창 위에 그려져 창 내용 일부(거래 버튼 등)를 가린다.
- **영향**: 모바일 폭에서 정거장 창의 일부 조작이 어렵다. 편대 선택을 해제하면 사라진다.
- **제안**: 정거장 창이 열려 있을 때는 선택 패널의 z-index를 모달보다 낮추거나 패널을 접는다. 또는 좁은 화면에서 모달을 전체 화면 시트로 띄운다. 390·768·1440px에서 다시 캡처해 확인한다.
- **상태**: 미해결.
