# P10 우주 확장 · 세력권 · 지역 경제 · 미지 자원 탐사

작업 브랜치: `feature/company-ops`. 이 문서의 월드는 모두 격리된 개발·테스트 월드다. 운영 DB, Render, 운영 배포 브랜치(`deploy/production`)에는 아무것도 적용하지 않았다. B안(원자재 ×0.25 가치사슬 가격)도 운영에 적용하지 않았다.

## 1. 적용 범위와 저장 보호

| 월드 | 생성 경로 | P10 기능 |
| --- | --- | --- |
| 기존 c0(5성계) 저장 | `new WorldSim(save)` | 없음. 변환하지 않는다. |
| P9(22성계) 저장 | `new WorldSim(save)` | 없음. 변환하지 않는다. `worldLayout: 'p9'` 유지. |
| 새 P9 월드 | `WorldSim.create(seed)` (기본값) | 없음. |
| 새 P10 월드 | `WorldSim.create(seed, { layout: 'p10' })` | 40성계, 세력, 안개(fog), 회사별 탐사 정보, 미확인 광구 |

- P10은 **새로 만드는 월드에서만** 켜진다. `expandP10`은 갓 생성된 P9 월드(22성계, `regionalV 1`, 플레이어 없음, 시간 0)가 아니면 예외를 던지므로 저장된 월드를 실수로 확장할 수 없다.
- 모든 P10 규칙은 `w.factions` / `w.fog` / `w.intel` 존재 여부로 게이트된다. 이 필드가 없는 저장은 종전 규칙을 그대로 쓴다(관문 항상 열림, 영역 위험 0, 정박 거부 없음, 설립 허가료 없음, 탐사 정보 없음).
- 저장 형식 버전·콘텐츠 버전은 올리지 않았다. 새 필드는 모두 선택적이다: `StarSystem.faction/region/charted`, `Field.geo`, `WShip.mineAcc`, `Station.faction`, `Company.standing`, `WorldState.worldLayout('p10')/factions/conflicts/intel/fog/factionClock`.
- 검증: `tests/p10-save-compat.test.ts` — P9 저장을 재적재해 10분 실행해도 세력·안개·탐사 정보·지오 광구·새 성계가 생기지 않음, c0 월드도 동일, P10 저장(세력·분쟁·탐사 정보·광구 깊이)이 왕복 후 같은 상태로 결정적으로 이어짐.

### 레거시 필드(기존 광구) 처리 규칙

- 기존 c0·P9 저장: 광구의 `mix`(공개 성분)를 그대로 쓴다. 변경 없음.
- 새 P10 월드:
  - 무법 변경의 P9 광구 6곳(`p9_shard_crystal`, `p9_dusk_vein`, `p9_blackgate_ore`, `p97_shard_resonance`, `p97_dusk_isotope`, `p97_blackgate_singular`)은 생성 시점에 `geo`로 바뀌고 `mix`는 삭제된다. 기존 성분은 단일 지층으로 그대로 옮기고, 파편 결정에만 깊은 공명 결정 광맥을 추가했다. 저장된 월드에서는 이 변환이 일어나지 않는다.
  - 그 밖의 P9 광구(앤빌·회수 항로 등)는 식별된 광구로 남는다.
  - P10 신규 광구 12곳은 처음부터 미확인 광구다.

**보류(승인 필요):** 기존 운영 저장을 P10으로 변환하는 마이그레이션은 구현하지 않았다. 필요하면 별도 설계와 승인, 백업·복구 절차가 선행되어야 한다.

## 2. 우주 구조 (40성계, 6세력)

P9의 22성계를 모두 보존하고 18성계를 추가했다(인덱스 22–39). 링크 26개를 추가했고 모든 성계가 연결된다.

| 세력 | 유형 | 수도 | 영역 |
| --- | --- | --- | --- |
| 연합 관리청 | 정부 | 헬리오스 | 수도·산업(리라·하버)·자원(고요한 공백) |
| 상인 길드 | 상업 | 아스트라 | 수도·자원(회수 항로)·중립 시장(교차로·자오선) |
| 세레스 공업연맹 | 산업 | 세레스 | 수도·산업(포지·킬른)·국경(갈라진 회랑) |
| 변경 광업동맹 | 채광 | 앤빌 | 수도·자원(드레이크·서리·툰드라·심층 광산)·국경(북방 관문·엠버) |
| 철갑 사령부 | 군사 | 불워크 | 수도·산업(아스널)·국경(집결 기지·성벽 회랑) |
| 해적 연합 (적대) | 해적 | 검은 관문 | 무법(감시자의 틈·황혼·송곳니)·국경(흉터 성운) |

무주 공역: 파편 항로·균열 공백·끝자락(무법), 기록 보관지(중립), 미개척 8성계(어스름·천정·장막·표류·메아리·심연·요람·늪).

### 지역 유형이 실제로 바꾸는 것 (`REGION_RULES`)

| 지역 | 정거장 설립 | 추가 수송 위험 | 비고 |
| --- | --- | ---: | --- |
| 수도 | 금지 | 0 | |
| 산업 | 허가료 25% | 0 | |
| 자원 | 허가료 10% | 5 | |
| 국경 | 허가료 10% | 15 (+20 분쟁 중) | 분쟁 시 관문 봉쇄 |
| 중립 | 무료 | 5 | |
| 미개척 | 무료 | 20 | 공개 성도 없음 |
| 무법 | 무료 | 30 | 해적 영역 |

- 허가료는 `foundStation`에서 `watchMoney('territory_licence')`로 기록되며 경제에서 빠진다(임의 생성 없음).
- 평판(`Company.standing`) −25 미만이면 해당 세력 시장 정박·설립이 거부된다.
- 평판 변화 근거: 세력 시장 판매(+min(2, 판매액/25,000)), 해적 토벌 전투(성계 세력 +0.5×공적, 해적 −공적).
- `patrol` 값은 설명용이다. 치안 효과는 각 성계의 `security` 값으로 표현된다(코드 주석도 이에 맞게 정정).
- 수송 위험(`territoryRisk`)은 기존 `routeRisk`에 더해져 조달·물류·광구 목표의 위험 결재에 반영된다.

## 3. 세력 경제 (`factionEcon.ts`)

세력은 추상 함대 전력(`strength`)과 기반시설(`infra`)을 가진다. **세력은 돈이나 물건을 만들지 않는다.** 60초마다:

1. **유지비**: 화학약품 0.02×전력, 군사·해적은 무기 부품, 채광·산업은 기계. 영역 내 공공 시장 재고에서 **예비분(목표의 30%)을 넘는 양만** 가져오며, 모자라면 전력이 천천히 줄어든다(0.001×부족률).
2. **함선 건조**: 전력이 교리 목표 미만이면 함선 레시피(합금·구조재 등)를 시장에서 가져와 전력으로 전환.
3. **건설**: 기반시설이 목표 미만이면 `{구조재 10, 합금 20, 기계 2}`/단위를 분당 0.2단위까지.
4. **제한적 확장**: 목표를 채운 비적대 세력은 인접 무주 성계 1곳만 점유 가능.
5. 가져온 재화는 `faction.stock`에 보관되어 정수 단위가 될 때까지 유지된다(버리지 않음). 모든 인출은 `observe('consume')` 이벤트로 기록된다.

수요는 실제 활동(전쟁 손실, 유지비, 기반시설 부족)에서만 생긴다. 시장 예산은 기존 `fundsMax` 한도를 그대로 쓰며 무제한 매입은 없다. 시나리오 E에서 확인한 바로는 철갑 영역 시장은 구조재·기계를 자체 공급하므로 실제 병목은 **합금**이다(재고 0에서 플레이어가 합금 600개를 판매하면 15분 건조량 증가, 판매 직후 매입가 64→53cr로 하락).

### 분쟁과 관문 봉쇄

- 전선(`P10_FRONTS`): 철갑–해적, 광업동맹–해적, 철갑–길드(교차로–성벽 회랑), 세레스–광업동맹.
- 관계 ≤ −60이고 양측 전력 ≥ 20이면 분당 0.6% 확률로 분쟁 시작. 매 주기 소모전, 국경 열기 상승. 2시간 경과, 한쪽 전력 < 10, 또는 30분 이후 확률적으로 종료. 종료 후 관계 +15. 최근 20건만 보관.
- 분쟁 중 해당 관문은 닫힌다(`gateOpen`). 이동 명령·행군 경로·점프·관리형 물류 경로(`usableRouteGate`) 모두 닫힌 관문을 피해 우회하고, 우회로가 없으면 정지한다.
- 분쟁 세력의 생산 공급은 국경 ×0.5, 그 외 ×0.8(`warSupply`).

## 4. 회사별 탐사 정보와 미확인 광구

### 탐사 정보 (`intel.ts`, `w.fog === 1`)

| 단계 | 의미 | 보이는 것 |
| --- | --- | --- |
| 0 미지 | 공개 성도에 없고 방문하지 않음 | 방문한 성계와 인접하면 '미확인 성계' 스텁만 |
| 1 성도 | 공개 성도 | 이름·세력·관문·공영 시설·식별된 광구 |
| 2 방문 | 자사 함선 도착 | 행성·정거장·숨겨지지 않은 광구 |
| 3 정밀 탐사 | 탐사 작업 완료 | 숨겨진 광구 |

- NPC 회사는 전지적이며 그 정보는 클라이언트로 가지 않는다.
- 동기화(`server/sync.ts`)는 회사별 버킷으로 분리한다: 미지 스텁 `sy.u:<회사>`, 미지 공역으로 이어지는 관문 이름을 가린 성계 `sy.r:<회사>`(관문 이름 → '미확인 점프게이트'), 탐사 정보 `in:<회사>`(해당 회사에게만). `legacyView`와 프로토콜-2 경로는 같은 결과를 내도록 테스트한다.
- 미확인 광구는 `geo`·`mix`를 보내지 않고 외형·규모·단서·숨김 여부와 5% 단위로 양자화한 매장량만 보낸다.

### 지질 모델 (`geology.ts`)

- 지층(`layers`, 누적 채굴 깊이에 따른 성분), 광맥(`veins`, 깊이 `after` 이후 특정 구역에서만 열림), 구역 4개.
- 채굴량은 정수 단위로 뽑히며(`hashId(fieldId#n)` 결정적 추첨), 함선별 나머지는 `ship.mineAcc`에 보관되었다가 작업 변경 시 광구로 돌아간다(생성·소멸 없음).
- 재생(regen)은 유지된다. 깊이(`geo.mined`)는 재생과 무관하게 증가한다.

### 시험 채굴 보고

- 성분은 **자사 함선이 실제로 캐낸 단위**로만 추정한다(`recordSample`).
- 신뢰도: 0 시험 채굴 필요, <30 표본 부족, <200 낮음, <1,000 보통, 그 이상 높음.
- 관측되지 않은 성분은 "없음"이 아니라 '최대 3/n 가능'(rule of three 상한)으로 표기하고, 깊이·구역에 따라 성분이 바뀔 수 있음을 함께 표시한다.

## 5. 회사 운영 연동 (`fieldOps.ts`)

새 채굴 경제를 만들지 않고 기존 엔진만 구동한다.

- `survey_field {field, group, samples, deliver?}`: 편대에 기존 채굴 작전 배정 → 표본 수 도달 시 정지·보고(성분·신뢰도·단위 가치·미관측 상한).
- `develop_field {field, group, deliver?, sell, miners, yard?, hull?}`: 계속 채굴·하역·판매(기존 경로), 채굴선 부족 시 하위 함대 목표로 증원, 산출 가치·문제(매장량 고갈, 편대 대기, 세력 분쟁) 추적.
- 지역 위험이 회사 정책 `maxRisk`를 넘으면 기존 'risk' 결재를 요청한다. 위험·예산 외에는 결재를 묻지 않는다.
- 플레이어가 편대에 다른 명령을 내리면 목표는 일시정지된다(플레이어와 다투지 않음).
- 본부 패널 '광구' 탭: 발견한 미확인 광구, 위치·세력, 관측 성분·표본·신뢰도, 배정 함선, 관련 업무.

## 7. 제한 사항

- 세력 함대는 추상 전력 수치이며 실제 함선으로 존재하지 않는다. 분쟁 손실도 수치 소모전이다.
- 평판 근거가 두 가지(세력 시장 판매, 해적 토벌)뿐이다.
- 교전(engagement) 안개 처리: 내용을 모르는 성계의 교전은 숨기지만, 교전 자체의 세부 정보 필터는 성계 단위다.
- 미관측 상한(3/n)은 현재 깊이·구역 기준의 통계다. 깊은 광맥은 나중에 열리므로 많은 표본 뒤에도 새 성분이 나올 수 있다(UI 문구로 경고).
- 세력 수도 정거장 설립 금지는 헬리오스·아스트라·세레스·앤빌·불워크의 기존 플레이어 확장 경로를 막을 수 있다(새 P10 월드에서만).
