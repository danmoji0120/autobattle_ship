# P15.0 — 대형함 방호·실효 화력·어뢰·방공 개선

GitHub 이슈 #5. 대상: 일반 대형함(전함·순양전함·드레드노트·중순양함). BB-EX는 범위 밖.
신규 함선·무장·부품 대량 추가, 전투 컴퓨터, 연구 확장은 후속 단계로 남긴다.

## 2. 구현 (BattleSetup.rules ≥ 1)

전투 규칙 버전 `BattleSetup.rules`를 추가했다. 기록된 전투(리플레이, 재시작 후 복원되는 진행 중 전투)는 `rules` 없이 저장돼 있으므로 기존 규칙으로 그대로 재현된다. 새 전투(월드 교전 2곳, 단독 전투, 개발 실험실)만 `BATTLE_RULES = 1`을 기록한다.
검증: 변경 후 코드의 `rules 0` 결과가 HEAD 코드와 14개 매치업 × 6시드에서 완전히 동일.

### 2.1 대형함 방호 — 선체 구조 (`ShipClassDef.structure`)
선체 등급별 콘텐츠 값(범용 규칙은 `World.applyHit`/`applyCrit`):
- **구획 흡수**: 한 발의 피해 중 `bulk`까지는 그대로, 초과분은 `absorb` 비율만큼 구획이 흡수(후방 피격은 절반만 흡수).
- **치명타 저항** `critRes`(후방 피격은 절반), **피해 통제** `dc`(치명타 지속시간 배율).

| 등급 | bulk | absorb | critRes | dc | 중어뢰 1발(측면) |
|---|---|---|---|---|---|
| 드레드노트 | 420 | 0.65 | 0.5 | 0.6 | 1,100 → 658 |
| 전함 | 380 | 0.55 | 0.4 | 0.7 | 1,100 → 704 |
| 순양전함 | 380 | 0.35 | 0.25 | 0.8 | 1,100 → 848 |
| 중순양함 | 320 | 0.3 | 0.2 | 0.85 | 1,100 → 866 |
| 그 외 | 없음 | | | | 1,100 |

주포탄(360)처럼 `bulk` 이하의 탄은 영향이 없어 포격전·소형함 간 전투는 그대로다. 장교 효과(critRes·dc·brace)와는 곱으로 함께 적용된다. 후속 콘텐츠(구형·실패작 선체)는 이 값을 낮추거나 없애 차이를 만든다.

### 2.2 어뢰 체계 — 플라즈마=비유도·무제한, 유도 어뢰=탄약 제한 (`WeaponDef.p15`)
- 기본 `torpedo`(중 플라즈마 어뢰): `p15.unguided` — 사격통제 예측 방향(발사 산포 포함)으로 직진, 유도·재표적 없음, 무제한 유지. 크고 느린 표적에는 여전히 잘 맞고, 기동하는 표적에는 빗나간다.
- 성장 콘텐츠 유도 어뢰: 표준 어뢰 `p15.magazine 4`(8발), 고급 대함 어뢰 `p15.magazine 3`(6발). 유도는 유지.
- 비유도 탄체는 궤적이 예측 가능해 방공 명중률 ×1.6(유도 어뢰와의 trade-off).
- 위력·속도·관통 수치는 바꾸지 않았다. 콘텐츠 검증기는 탄약 제한 없는 유도 어뢰에 경고를 낸다.

### 2.3 대형함 무장 운용
전열함(line)의 부포(포탄, 피해 < 250)는 지휘관 지정 표적을 무조건 따르지 않고 스스로 고른다:
어뢰를 가진 함이 사거리 1.5배 안에 있으면 우선(×3), 같은 함의 다른 포탑이 이미 충분히(초계함 2·호위함 3) 쏘고 있는 소형 표적은 감점. 주포와 다른 함종은 기존 규칙 그대로.

### 2.4 방공
- 위협 평가: 탄체 위력 가중(≤150), 유도탄은 자신·600 m 내 아군을 노릴 때, 비유도탄은 실제 자기 함이나 겨냥된 아군과 **충돌 궤적일 때만** 우선(빗나갈 탄은 무시).
- 분배: 탄체마다 추적 중인 방공 포탑 수를 기록(`pdLoad`, 매 틱 재계산), 격추에 필요한 수(탄체 HP+1)를 넘는 추적은 감점해 다른 탄체로 분산.
- 계산 비용: 방공 포탑 재표적 때 탄체당 함선 2척(자신·피겨냥 아군)만 궤적 검사.

- 대형함의 일방적 약세는 완화됐다: 생존 시간 약 2배, 소수·저가 어뢰정(M13)과 이슈 사례(M3)는 역전, 방공 호위가 붙으면 균형(M7)~우세 근접(M14).

- 대형함 부포는 동시에 여러 표적을 쏜다(함당 표적 0.75 → 1.84, 가동률 32% → 53%, M1).

- 전투당 계산 시간: 대체로 전투가 길어진 만큼 증가(M1 33→53 ms). 같은 길이의 전투(M9·M10·M12)는 차이 없음.
- 대규모(`RULES=n npx vite-node scripts/combat/perf.ts -- 1800 1`, 순양함·방공 구축함·뇌격 초계함 혼합 200척): 틱 평균 1.46→1.60 ms(2자전), 1.53→1.76 ms(3자전), 1.44→1.67 ms(증원) — +10~15%, 30 Hz 예산의 4~5%. 결정성 유지(같은 시드 같은 digest).

## 4. 호환성

- 저장: 새 필드는 전투 설정(`setup.rules`)뿐. 월드 저장의 기존 교전은 `rules` 없이 남아 기존 규칙으로 재생·복원된다.
- 피팅·콘텐츠: 무장 id·장착 규칙 불변. `WeaponStats.p15`, `ShipClassDef.structure`는 선택 필드.
- 단독 전투 공유 링크(`?auto&seed=`)는 `rules` 파라미터가 없으면 현행 규칙.
- BB-EX 시험 설정(`trialSetup`, `angelDescentSetup`)은 `rules`를 기록하지 않아 기존 규칙 그대로(BB-EX 조정 결과 보존). 월드에서 BB-EX가 끼는 새 교전은 rules 1.
