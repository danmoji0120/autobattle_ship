# P16.4 — 클라이언트·스커미시·함재기 렌더링 (부분 완료 / 자동 검증 통과)

기준: `a7a74fe`, P16.4 코드 `ae77243`. 개발 브랜치 `ccr-f3f46604-1jievd`.

## 구현된 기능

- **스커미시 전용 여명급**: 게임 월드의 `HullDef.preview`를 유지하면서 스커미시 카탈로그에서만 여명급을 선택할 수 있다. 편성된 아군 무장 중 `craft`가 있으면 해당 전투만 `rules: 3`; 그 밖의 기본 스커미시는 `BATTLE_RULES = 2`를 사용한다.
- **스커미시 전투 컴퓨터**: 미공개 `cpu_carrier`를 시험용 CPU 선택 목록에 포함한다. 게임 내 실제 월드 구매·건조·상점·설계도 공개는 그대로 차단한다.
- **비행체 시각화**: `src/render/craftMeshes.ts`에 3개의 `THREE.InstancedMesh` 배치(전투기·뇌격기·요격기). `CraftPool`의 실제 OUT 기체 위치·속도·진영을 읽기만 한다. 기체별 메시 생성 없이 동적 증원에 맞춰 버퍼 확장, 역할별 날개 실루엣·진영별 색상 제공.
- **전투 이펙트**: 실제 출격·격추 이벤트에 효과를 표시한다. 기관포·요격기의 실제 명중 중 정해진 간격의 `craftShot`만 예광탄으로 그린다. 시각화 이벤트는 RNG와 피해 계산을 바꾸지 않는다. 항모에는 임시 격납 갑판 모형을 붙였다.
- **전투 HUD**: 기존 선택 부대 상태 줄 하나에 항공단 출격/정원, 예비기, 관제 한도, CAP 비행대 수를 표시한다. 별도 상시 패널을 추가하지 않는다.
- **기존 피팅 UI**: H 슬롯, flight 베이, craftSummary, airText는 P16.2·P16.3에서 연결되어 있다. P16.4에서 피팅 구조를 별도로 확장하지 않았다.

### 실기체 공중 렌더 성능

시험: 단일 브라우저, 1280×720, Chromium Headless + SwiftShader 소프트웨어 WebGL. 규칙 3, 시작 거리 1300m, 적 전함 24척은 함포 무장만 탑재(PD 없음), 첫 5프레임 워밍업 제외. `WebGL.finish()`으로 완료를 기다린 프레임 벽시계 시간이다. 실 GPU 성능이나 사용자 기기의 FPS를 의미하지 않는다.

| 800 | **807** | 807 | 16726.77 | **17.36 / 25.70 / 33.60 ms** | **0.220 ms** |

총 공중 기체는 실측으로 검증했고, 측정 구간에서 격추는 0기다. 따라서 **대량 시각화** 측정에는 유효하지만, 방공·격추 폭발이 발생하는 고강도 전투의 최악 성능까지 증명하지는 않는다. 약 800기에서 최대 프레임 33.6ms는 60FPS(16.7ms) 실시간 렌더 보장이 아니다.

첫 번째 브라우저 측정(https://github.com/danmoji0120/autobattle_ship/actions/runs/44231016227)은 비행체가 0기인 상태에서 프레임을 재는 오류가 있었다. 해당 수치는 **무효** 처리했고, 시작 거리를 수정하고 공중 기체 수 70% 이상 조건을 추가해 재시험한 결과만 위에 기록했다.

## 유지된 공개·운영 정책

- `carrier_dawn.preview = true`. 일반 월드의 구매·건조·설계도·상점 제한을 유지.
- 기본 `BATTLE_RULES = 2`; 항모가 포함된 스커미시와 인증된 실험실의 명시적인 시험에만 규칙 3 사용.
- 배포용 `deploy/production` 브랜치와 운영 서버, 운영 DB, 운영 마이그레이션은 건드리지 않았다.
- 검증 workflow `.github/workflows/p16-verify.yml`는 개발 브랜치에서만 실행한다.

## 남은 검증 / 부분 완료 이유

1. **관리자 실험실 실제 브라우저**: `?devskirmish=1`은 서버 인증 및 별도 관리자 권한이 필요하다. 그 인증을 우회하지 않았으므로 규칙 선택 조건 패널과 실험실 피팅을 실제 브라우저에서 클릭하는 E2E는 미실행이다. P16.3의 데이터·설정 단위 검증은 통과.
2. **세계 저장 사본의 항모 잔해**: 일반 월드에 항모가 공개되지 않아, 격침 항모의 H 장비가 실제 인양 잔해로 남는지 통합 테스트는 미실행이다.
3. **고강도 항공전 GPU 성능**: 이번 테스트는 PD 없는 상대 24척에 대한 대량 렌더 하네스다. 함재기 격추·PD 요격·교전 이펙트가 많은 경우 및 실제 GPU/모바일 브라우저 검증을 추후 수행해야 한다.
4. **기존 기술 부채**: `dev11-combat` 2건과 `shipyard` 3건은 이전부터 있던 별도 실패다. 이번 CI는 P16 관련 48건만 검증했고 전체 회귀는 실행하지 않았다.
5. **하이브리드 함급 확장성**: `src/world/sim.ts`의 `airValue()`는 표준 로드아웃에 craft가 없는 함급을 조기에 제외한다. P16.5 또는 H 슬롯 혼합함 추가 전에 실제 장비 기준으로 수정할 것.

P16.4의 렌더러·스커미시 코드는 통합됐고 자동 검증은 통과했지만, 위 조건을 남긴 채 **최종 완료라고 선언하지 않는다**.
