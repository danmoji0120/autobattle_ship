## 2. 선체

- 각 선체는 고유 실루엣(`hulls17.ts`, mesh.scale 1 — 하드포인트 좌표가 모델 좌표 그대로)과 고유 구조(하드포인트·베이·전력·질량·구조·경제)를 가진다. 기존 소재만 사용.
- 성능·가격은 고르게 맞추지 않았다: 걸작(팔시온·아이기스-II), 고가 엘리트(레비아탄-II·솔라리스), 싼 양산형(민병·돌개바람), 구식(유물·철현·군주), 실패작(폐선·고철).
- 제조사 제품군: 헬리오스 조병창, 바스티온 중공업, 세레스 공업, 연합 방위조선, 상인 길드 조선, 러스트포트 자유조선, 코발트 양산공창, 구 제국 군수창, 해적 개조업체, 철갑 사령부 공창, 바르카·연합 합작.
- 선체마다 제조사 권장 컴퓨터(`HullDef.cpu`)가 있다. **플레이어는 컴퓨터를 따로 사야 한다**(구매 선체에 무료 컴퓨터 없음). NPC는 권장 컴퓨터를 단다(npc17 월드).

### 획득 경로 분리 (소유 ≠ 설계도 ≠ 연구 ≠ 생산 ≠ 판매처)
- `sale`: 완성함을 파는 공공 조선소. 양산형은 넓게, 엘리트는 소수 정거장, **10척은 완성함 판매 없음**(벌떼·히드라·사략선·솔라리스·폐선·노급 3·항모 2).
- 설계도: 상점·상업·세력·계약·인양·탐사(탐사는 P19 연결 지점만, 탐사 시스템은 추가하지 않음).
- `build.tech` + `build.facilities`: 설계도 외에 필요한 연구·공장.
- 항모(벌집·방주)는 기존 미리보기 공개 플래그를 그대로 둔다.

## 3. 무장 메커니즘 (실제 전투 엔진 동작)

| 메커니즘 | 무장 | 실제 동작 |
|---|---|---|
| 분열(container) | 군집 컨테이너(20자탄)·경량 확산(8)·중 관통 컨테이너(12) | 모탄이 표적 520m 앞에서 열려 **실제 개별 탄체** 20발 생성. 자탄마다 표적·요격 HP가 따로 있다. **분열 전 모탄이 요격되면 자탄은 0발.** |
| 2단(stage) | 2단 돌입 미사일·어뢰 | 순항(속도×0.42) 중 요격 어려움 → 600m에서 돌입 가속·선회 상승 |
| 기만(decoy) | 기만 유도탄(3)·유령 군집(6) | 진짜 탄과 같이 나는 기만체 사출, 방공이 기만체에 사격 낭비 |
| 동시 탄착(tot) | 동시 탄착 미사일·순항탄 | 일제사 탄들의 도착 시각을 맞추도록 경로를 늘려 부채꼴 진입 |
| 기뢰(mine) | 근접 기뢰 투하기·대형 함정 기뢰 | 투하 후 무장 시간 → 근접 시 폭발, 수명 경과 소멸 |
| 축전(charge) | 축전 펄스포(1.2초)·축전 랜스(2.2초) | 충전 시간 동안 발사 보류(실제 사격 지연) 후 고화력 단발 |
| 지속 빔(sustain) | 소형·지속 절단 빔·대형 지속 빔 | 1.5~4초 유지, 0.25초 단위 틱 피해, 표적 이탈 시 끊김 |
| 연쇄 아크(chain) | 소형 아크·연쇄 아크 투사기 | 명중 후 반경 내 다른 적 함선으로 2~3회 도약, 도약마다 감쇠 |
| 폭렬(burst) | 플라즈마 폭렬포(M/L) | 근접 신관으로 표적 옆에서 터져 반경 피해 |
| 근접 탄막(flak) | 근접 신관 탄막포·중 탄막 포대 | 방공 사격이 폭발 반경 안의 탄체를 함께 잡음 |

일반 무장 3종: 양산 40mm 기관포, 장포신 곡사 주포, 대구경 코일포.

예시(테스트로 확인한 값): 분열 이벤트 1회당 정확히 20개 자탄(`tests/p17-mech.test.ts`), 분열 전 요격된 모탄은 자탄 0.

## 4. 전투 컴퓨터·내부 부품

컴퓨터는 **행동만** 바꾼다(검증 규칙: 컴퓨터에 fx 없음). 같은 원형이라도 `CpuTune`(range·volley·guide·cover·energy)이 다르면 실제로 다르게 싸운다.

| 제품 | 원형 | 실제 동작 |
|---|---|---|
| 미사일 관제 | missile | 미사일 사거리×0.82 유지, 발사기 최대 2.5초 대기 후 일제 발사, 유도 선회 ×1.15 |
| 보급형 미사일 관제 | missile | 1.2초 일제 대기만, 판단 1.5초 |
| 원거리 사격 | artillery | 사거리 ×1.08까지 물러나 사격 |
| 근접 강습 | swarm | 군집 원형보다 30% 더 근접, 판단 0.6초 |
| 함대 방공 | picket | 반경 1,700m 아군을 노리는 미사일·어뢰를 우선 요격(행동 상태와 무관) |
| 전열 유지 | line | 0.6초 갱신, 사거리 ×1.05 |
| 측면 기동 | flank | 표적 정면 회피, 측후방 135° 사분면으로 우회 |
| 에너지 관리 | line | 실드 30% 미만이면 적 사거리 밖으로 후퇴·재충전 후 복귀 |
| 긴급 지원 | support | 0.5초 판단, 대기 거리 ×1.2 |

내부 부품 10종은 모두 대가가 있다(질량·전력·다른 배수 감소). 예: 후연소 추진기 속도 +25%·회피 +5% / 선체 내구 -5%, 근접 신관 지휘기 방공 +30% / 명중 -5%.

## 5. 경제 연결 (P17.3g)

- **새 월드에만** 공공 정거장 판매 행 추가(`stockParts17`, 생성 옵션 `computers: 'p151'`일 때). `stockComputers`(P15.1 이관에도 쓰임)는 바꾸지 않았다.
- 정거장 판매: astra·bastion·helios·drakeout·cinderco에 일부 무장/컴퓨터/부품. **엘리트 메커니즘(군집 컨테이너·중 관통 컨테이너·축전 랜스·대형 지속 빔·대형 함정 기뢰·유령 군집, 미사일 관제·에너지 관리 컴퓨터)은 판매하지 않고 연구+자체 생산만.**
- 모든 신규 무장·컴퓨터·부품에 연구 해금과 생산 레시피가 있다(완전히 못 구하는 것은 없음).
- **NPC 사용(선택 옵션 `npc17: 'p173'`)**: 해적 무리 편성의 홀수 칸을 P17 해적 계열 선체(유물·흑익·넝마주이·고철·벌떼·폐선)로 바꾸고, 프리셋 무장 + 제조사 권장 컴퓨터를 단다. 옵션이 없는 월드(표준 월드·기존 저장본)는 기존과 완전히 같다.

## 6. 그래픽·연출

- `src/render/mech17Fx.ts`: 분열(섬광·링·껍데기 두 조각·자탄 수만큼 불꽃), 2단 점화, 기만체 사출, 축전 발광(**실제로 충전하는 무장만**), 연쇄 아크, 폭렬, 탄막, 기뢰 점멸, 지속 빔. 자탄·기뢰·2단 탄의 궤적 스타일 분리.
- 명중 이펙트는 피해량에 비례(`sqrt(dmg/160)`, 0.35~2.2배).
- 엔진 피격: 엔진 치명타 시 폭발·연기, 엔진 손상 또는 내구 30% 미만에서 분사염이 끊긴다.
- 기존 풀(파티클·궤적·링·섬광)을 재사용, 메시 생성 없음. 카메라 흔들림은 기존 설정(꺼짐/약/중/강)을 따름.
- **시각 RNG 분리**: 연출은 `Math.random`만 사용하고 전투 RNG는 건드리지 않는다. `tests/p17-replay.test.ts`가 프레임마다 `Math.random`을 소비하면서도 리플레이가 비트 단위로 같음을 확인.

## 8. 한계·보류

- **측면 기동 한계**: 자유롭게 선회하는 단독 표적은 가장 가까운 위협(=측면 기동함)에 함수를 계속 돌리므로 후방 진입이 어렵다. 테스트는 표적 선회를 고정해 기동 자체만 확인했다.
- **npc17은 선택 옵션**: 표준 월드 기본값으로 켜는 것은 밸런스(P17.4) 판단이 필요해 보류.
- NPC 함선은 fx(부품 배수)를 받지 않는다(기존 규칙). NPC P17 함선도 무장·컴퓨터만 반영.
- 긴급 지원 컴퓨터는 기존 support 원형의 튜닝판(새 원형 아님).
- P17 절차 생성 선체의 거리별 LOD는 따로 만들지 않았다(기존 외부 모델 LOD만 존재). 스파이널 포 전용 포미(breech) 렌더도 미구현.
- 항모 2종은 미리보기 플래그 유지(공개하지 않음).
