# Content graphic assets

Files here are served at `./assets/content/<path>` and must be registered in a content pack
(`src/content/packs/*/index.ts` or `assets.ts`). `npm run content:check` fails on unregistered or missing files.

- `models/`           ship and variant models (`.glb`, ≤ 2 MB, +z forward, origin at hull centre, 1 unit = 1 game unit),
                      optional LOD models (`*_lod.glb`, ≤ 768 KB). Every model is pinned by `sha256`
                      (`npm run models:hash -- --write`); the client loads it as `<file>?v=<sha>`.
- `models/fixtures/`  model-loader TEST fixtures (generated by `npm run models:fixtures`), registered with
                      `fixture: true` and usable only by `dev` hulls. Not game art.
- `portraits/`        commander portraits (`.webp`/`.png`, 512×512, ≤ 300 KB)
- `icons/`            equipment / item / facility icons (`.svg`, or `.webp`/`.png` 128×128, ≤ 64 KB)

Models are committed to the repository directly (no Git LFS, no external storage) so every checkout, cloud
session and deploy has them. Full rules: `docs/CODEX_CONTENT_GUIDE.md` §26–§33, `docs/CONTENT_SCHEMA.md` §6.
