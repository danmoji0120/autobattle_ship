# SIDERARIUM Shipworks — 콘텐츠 검토 메모

이 팩은 `minContentV: 3`인 성장 월드용 데이터 팩이다. 기존 함선, 엔진, 지휘관 AI, 운영 세이브는 수정하지 않는다.

## 선체와 역할

| 선체 id | 함급 | 주전술 | 대가 |
|---|---|---|---|
| `sid_frigate_kestrel` | frigate | 고속 고정 어뢰 돌입 | 체력 0.72배, 장갑 0.68배, 좁은 전방 사각 |
| `sid_light_cruiser_prism` | light_cruiser | L 척추포 대함 저격 | 체력 0.73배, 장갑 0.65배, 부포/방공 부족 |
| `sid_battlecruiser_tempest` | battlecruiser | 미사일 VLS 대량 포화 | 체력 0.77배, 장갑 0.62배, 탄약·운영비 |
| `sid_hauler_bulwark` | hauler | 자위용 무장 호송선 | cargo 1,600 vs 벌크선 3,200, 순항 44 vs 66, 운영비 3,000 vs 1,500 |

각 선체에는 `_std` 기본형과 2개의 실질적 구조 개장형, 선체/특수 개장 설계도가 있다. 프리셋은 **무장만** 설정한다. 내부 모듈(반응로·장갑·엔진)은 플레이어가 별도로 장착한다.

## 현재 구현 경계

- 새로운 무장·효과·AI·전투 판정·정거장 기능을 추가하지 않는다. 기존 P5 무장/모듈과 함급 AI를 사용한다.
- 시각 모델은 기존 함급/추가 절차적 실루엣으로 표시된다. 각 선체 전용 GLB 모델/LOD는 **미제작**.
- `sid_hauler_bulwark`는 무장 **화물선**이지 이동식 정거장이나 수리 지원 플랫폼이 아니다.
- `sid_light_cruiser_prism_overload`의 감마포는 연구 `gamma_lasers`와 별도 무장 확보가 필요하다.

## 검증

별도 소규모 데이터 검사(2026-11-08):
- 새 ID 중복 없음, 선체/변형/프리셋/설계도 참조 일치.
- 14개 프리셋(총 87개 무장 장착)이 하드포인트 크기·종류·마운트, 본체 전력·질량 한도 통과.
- 4 선체/12 변형/14 프리셋/12 설계도 등록 확인.
- 공개 정거장 berth 기준으로 판매 위치 선정.

**미검증(병합 전 필수):** `npm run content:check`, `npx tsc --noEmit`, `npm test`, 실제 피팅 화면·전투 시뮬레이션·가격/보급 밸런스 검증. 이 파일은 공식 테스트 통과를 선언하지 않는다.

## 리뷰 권장 시나리오

1. 황조롱이급 대 구축함 PD 함대 / 대 PD 없는 중순양함: 어뢰 요격과 손실 확인.
2. 프리즘급 감마 과부하형 대 고속 호위함: 사격각·추적 난이도 확인.
3. 폭풍우급 VLS 포화형 대 동일 비용 방공 구축함 편대: 탄약·킬 효율 측정.
4. 성채급 대 해적 습격 및 일반 벌크선: 1시간 운송량·손실·유지비 비교.

판정 기준은 모든 함선이 강한 것이 아니라, **선택한 역할에서 확실히 강하고 반대 상황에서는 확실히 불리한 것**이다.
